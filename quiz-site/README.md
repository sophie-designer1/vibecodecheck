# QR 퀴즈 랭킹

학생들이 QR을 찍어 퀴즈를 풀면 1등부터 순위가 나오고, 설문조사도 할 수 있는 사이트입니다.

## 실행
```bash
cd quiz-site && npm install && npm start
```
터미널에 나오는 **"같은 와이파이 학생용 주소"**로 출제자 화면을 열면 QR이 그 주소로 만들어져 학생 폰에서 접속됩니다.
(인터넷 배포 시에는 배포된 주소로 접속하세요. `PORT`, `DATA_FILE` 환경변수 지원)

## 진행 흐름
1. 홈에서 **퀴즈**(정답 지정, 순위) 또는 **설문**을 만들고 "QR 코드 만들기"
2. 학생이 QR → 닉네임 입력 → **대기실** 입장 (출제자 화면에 입장자 실시간 표시)
3. 출제자가 **시작하기** → 모든 학생이 동시에 문제 화면으로 이동
4. 출제자 화면에 순위/설문 결과가 실시간 집계, **마감하기**로 종료
- 순위: 점수 높은 순 → 같으면 빨리 푼 순 (시작 시각 기준 서버 측정)
- 정답은 서버에만 있고, 시작 전에는 문제도 전송되지 않습니다.
- 데이터는 `data/quizzes.json`에 저장됩니다. (출제자 링크의 `key`는 비밀로 유지)
